# TLS и TURN: публичный домен, Let's Encrypt, отдельный TURN-поддомен

Reverse proxy деплоера (например, Caddy — в compose он не входит, см. docs/DEPLOY.md) терминирует HTTPS (веб + wss LiveKit) с сертификатами Let's Encrypt по HTTP-01. Self-signed невозможен: LiveKit требует доверенный серт, и браузер не отдаст микрофон без HTTPS. TURN для удалённых участников — встроенный TURN/TLS LiveKit на поддомене `turn.<домен>`: это отдельный TLS-листенер, его сертификат должен соответствовать своему hostname. Одна A-запись в существующем домене, отдельного домена не нужно. Порты по умолчанию 3478/UDP и 5349/TCP; при блокировке корпоративным файрволом — переезд на 443 со SNI-роутингом.
