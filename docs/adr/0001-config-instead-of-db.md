# Без базы данных: config.yaml — единственный источник сотрудников

Вся идентичность продукта (логины, bcrypt-хэши паролей) живёт в config.yaml, который бэкенд читает при старте. Сознательный отказ от СУБД ради «docker compose up за 2 минуты»: нет миграций, нет отдельного хранилища, бэкап = копия конфига. Redis в стеке — только служебная очередь LiveKit Egress, не хранилище данных продукта. Пересмотреть, когда появится состояние, не влезающее в конфиг и файлы (история, роли, аудит).
