# ADR-0004: AI-сводки — флаг в sidecar, воркер-секретарь, секреты в .env

## Контекст

Эпик 2 (AI-секретарь): кнопка AI рядом с кнопкой записи заказывает сводку встречи.
Запись — уже существующий egress (ADR-0002), нужен только путь «пометить запись как
требующую разбора» и сам разбор: STT → LLM.

Метаданные комнаты LiveKit не подходят как долговременный флаг: стираются на стопе
и не переживают рестарты. Секреты STT/LLM нельзя класть в config.yaml — он в гите.

## Решение

- **Кнопка AI — только при идущей записи.** Запись всегда стартует обычной кнопкой;
  кнопка AI появляется, когда запись идёт, и `POST /api/recording/summary` заказывает
  сводку для неё (повторный клик — ничего). Так старт записи и заказ сводки не
  путаются.
- **Флаг — в sidecar записи.** При старте sidecar пишется сразу (не на стопе, как
  раньше); заказ сводки дописывает в него `summary: true` и обновляет метаданные
  комнаты до `{"recording":true,"summary":true}` — live-статус для UI. Имя файла
  идущей записи бэкенд держит в памяти (`activeRecName`): FileResults активного
  egress может быть пуст до финализации.
- **Отдельный воркер** `server/cmd/secretary` (свой compose-сервис, тот же образ):
  сканирует каталог записей, берёт mp4 с флагом `summary` и mtime старше 30 с
  (egress закрыл файл), гонит через OpenAI-совместимый STT
  (`/v1/audio/transcriptions`), транскрипт — через LLM (`/v1/chat/completions`).
- **Результат — `{имя}.summary.json`** рядом с mp4: статусы
  `transcribing → summarizing → done`, при ошибках — ретраи (3 попытки, пауза
  минута), затем `error`. Атомарная запись (tmp + rename). Бэкенд лишь читает
  файл и отдаёт поля в `/api/recordings` — воркер единственный писатель, гонок
  нет.
- **Секреты — `.env`** (`env_file` у сервиса, `.env` в .gitignore, шаблон
  `.env.example`): `STT_BASE_URL/STT_API_KEY/STT_MODEL`,
  `LLM_BASE_URL/LLM_API_KEY/LLM_MODEL`. Воркер не читает config.yaml.

## Следствия

- Сводка появляется в табе «Сводки» у записи; транскрипт хранится в summary.json
  (в UI пока не показывается).
- Сводку можно заказать в любой момент идущей записи (не только при старте);
  снять заказ нельзя — только остановить запись (можно: убрать флаг вручную).
- Без `.env` стек поднимается, воркер ждёт настройки.
