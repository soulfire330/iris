# Виртуальный офис

Корпоративный голосовой хаб команды: одна постоянная комната, сотрудники описаны в config.yaml, записи встреч по кнопке. Разворачивается через docker compose.

## Language

**Сотрудник** (Employee):
Пользователь хаба, описанный в config.yaml; идентичность — login + password.
_Avoid_: юзер, аккаунт

**Участник** (Participant):
Сотрудник, подключённый к комнате в данный момент (термин LiveKit для presence).
_Avoid_: юзер

**Комната** (Room):
Единственная постоянная комната команды; существует, пока в ней есть участники.
_Avoid_: конференция, звонок

**Запись** (Recording):
Аудио-файл отрезка жизни комнаты, начатый/остановленный кнопкой в интерфейсе.
_Avoid_: рекординг

**Сводка** (Summary):
Краткий пересказ записи (тема, решения, договорённости), собранный Секретарём из транскрипта.
_Avoid_: саммари, протокол

**Секретарь** (Secretary):
Воркер AI-сводок (`server/cmd/secretary`): распознаёт речь записи (STT) и составляет Сводку (LLM); настройка — `.env`.
_Avoid_: AI-воркер, бот
